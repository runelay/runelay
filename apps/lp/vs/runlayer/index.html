Runelay is not Runlayer

Runelay, an open source MCP gateway, is a free project you host yourself. Runlayer is a separate company with an enterprise product. The names are one letter apart, so search engines often swap them.

You want Runelay if

  • You use Claude Code, Codex, Cursor or Grok and want them to share accounts, skills and memories.
  • You want a desktop app or one container on your own server.
  • You saw runelay migrate, runelay connect or a key that starts with rnl_.

You want Runlayer if

  • You are evaluating a governance platform for agents across a company.
  • You need policies, approvals and security scanners managed by a vendor.
  • You were sent a link to runlayer.com or docs.runlayer.com.

About the name

Runelay is written with an “e” after “run”. The project and the site are runelay.com and github.com/Andsu-dev/runelay. It has no relation to Runlayer and makes no claim about that product beyond what its own site states.

Questions

Is Runelay related to Runlayer?

No. They are separate projects from different authors. Runelay is an MIT licensed MCP gateway by Anderson Medeiros.

Why do search results show Runlayer when I type runelay?

The names differ by one letter, so search engines and assistants autocorrect one to the other. Searching for “runelay MCP gateway” or going to runelay.com avoids it.

Where do I download Runelay?

At runelay.com/download for Mac, Windows and Linux, or with curl -fsSL runelay.com/install | sh on a server with Docker.
