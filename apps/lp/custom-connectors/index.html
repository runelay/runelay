Connect any MCP server or API

The catalog is a shortcut, not a limit. Add a remote MCP server, a local command or an OpenAPI spec to Runelay, an open source MCP gateway, and every agent gets its tools through the same endpoint.

Three ways in

What you giveGood for
Remote MCPThe server URLPublic or internal MCP servers over HTTP
Local commandA command, arguments and env varsMCP servers that run as a process, like npx packages
OpenAPIA spec in JSON or YAMLYour own REST API, with no MCP server to write. Each operation becomes a tool.

Sign-in that just works

  • Paste a remote MCP URL and Runelay detects whether it wants OAuth, a key in a header or nothing at all.
  • OAuth runs when you save. Tokens are stored encrypted and refreshed by Runelay.
  • Provider without automatic client registration, like Google? Use your own OAuth client: register PUBLIC_URL/v1/oauth/callback as the redirect URL and paste the Client ID and secret.
  • Headers, env vars and secrets are encrypted at rest with AES-256-GCM. Agents never see them.

One login, every agent

The connection name becomes the tool prefix, so a connection named billing exposes tools like billing.list_invoices. Claude Code, Cursor, Codex and every other agent with a Runelay key find them with search_tools and run them with call_tool.

Already configured in an agent? runelay import turns the MCP servers in your agent configs into connections, or paste the config file in the panel.

Questions

Can Runelay reach a server on my private network?

Yes, if you allow it. Requests to private, loopback and link-local addresses are blocked by default. Set RUNELAY_ALLOW_PRIVATE_URLS=true on the Runelay server to reach internal servers.

Can I run a local MCP server with npx?

Yes. The desktop app runs local commands with the tools installed on your computer. On a server they are off by default: set RUNELAY_ENABLE_STDIO=true, and only an owner or admin can create them. The Docker image ships without Node.

Do my API keys reach the agents?

No. Headers, env values and OAuth tokens stay on your server, encrypted with your RUNELAY_SECRET. Agents only hold their Runelay key.
