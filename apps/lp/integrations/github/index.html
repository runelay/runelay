GitHub on Runelay, an open source MCP gateway

GitHub's official MCP server, behind your own Runelay endpoint. Log in once with OAuth and every agent can read repositories, work on issues and handle pull requests with your GitHub permissions.

GitHub's own MCP server, shared by every agent

The catalog entry points at api.githubcopilot.com/mcp/, the remote MCP server GitHub maintains. Runelay does not wrap or rewrite its tools; it holds the token and forwards the calls.

GitHub groups the server's tools into toolsets. Its documented default set is context, repos, issues, pull requests and users, which covers the day-to-day work below.

What your agent can do on GitHub

  • Repositories and code. Read files with get_file_contents, search with search_code and search_repositories, inspect history with list_commits and get_commit, and write with create_branch, create_or_update_file and push_files.
  • Issues. Find them with list_issues and search_issues, read one with issue_read, open or edit with issue_write and manage sub-issues with sub_issue_write.
  • Pull requests. List, search and read pull requests, open them with create_pull_request, update them, leave a review with pull_request_review_write and merge with merge_pull_request.
  • Context. get_me tells the agent who it is acting as, and search_users finds people by name.

Try asking

  • “Summarize the open pull requests in my repo and say which ones are waiting on me.”
  • “Find where the rate limiter is defined in this repository and explain it.”
  • “Open an issue for the failing login redirect with the steps I just described.”

How it signs in

  • OAuth through the Runelay broker. You approve a GitHub OAuth app; no client of your own to register.
  • Scopes requested: repo and read:user. The agent can reach the repositories your GitHub account can reach, private ones included.
  • Prefer a token? Paste a GitHub personal access token instead, and its permissions set the limit.

What this connection does

Repositories, issues and pull requests. Runelay connects to the GitHub remote MCP server at https://api.githubcopilot.com/mcp/ and puts its tools behind your own endpoint.

Agents find them with search_tools and run them with call_tool, so the GitHub tool list is not loaded into context until it is needed.

Questions

Can the agent push code or merge pull requests?

Yes. The default toolsets include push_files, create_or_update_file and merge_pull_request, so the agent can write wherever your account can. If that is too much, connect with a fine-grained personal access token limited to the repositories and permissions you choose.

Does it see my private repositories?

With OAuth it does: the repo scope covers private repositories your account can reach. A fine-grained token narrows that to the repositories you select.

Is this the same server Copilot uses?

It is the remote GitHub MCP server at api.githubcopilot.com/mcp/, maintained by GitHub. Runelay connects to it from your server and keeps the token there.
