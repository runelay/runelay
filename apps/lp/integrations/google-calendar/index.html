Google Agenda on Runelay, an open source MCP gateway

Your agents read the agenda and put events on it. Runelay ships its own Google Calendar tools and calls the Calendar API with the account you connect.

Built into Runelay

Runelay calls the Google Calendar API itself with your Google token, with no third-party MCP server in between. account_whoami shows which Google account is connected.

Tools

  • Calendars. list_calendars returns every calendar on your list with its id and your access role.
  • Read events. list_events lists a calendar in start order, between two dates or matching a text query.
  • Create events. create_event takes timed or all-day events, with a time zone when the times have no offset, and returns the event link.
  • Delete events. delete_event removes an event from a calendar.

Try asking

  • “What is on my primary calendar tomorrow?”
  • “Block Friday from 2pm to 4pm for focus time, São Paulo time.”
  • “Delete the dentist appointment next week.”

How it signs in

  • Google OAuth through the Runelay broker. No Google Cloud project of your own; Runelay renews the token.
  • Scopes: calendar, calendar.events, plus openid, userinfo.email and userinfo.profile.

What this connection does

Agents find these tools with search_tools and run them with call_tool, so they only enter the context when a task needs them.

Questions

Can the agent change an existing event?

Not today. The tools list, create and delete events; there is no update tool, so a change is a delete plus a new event.

Which calendars does it see?

Every calendar on your calendar list, shared ones included. list_calendars shows your access role on each.

How do I make an all-day event?

Pass dates as YYYY-MM-DD. The end date is exclusive, so a one-day event on the 10th ends on the 11th.
