Connect Codex to Runelay

Runelay, an open source MCP gateway, gives Codex one endpoint for every account you connected. Add it once and Codex sees the same tools, skills and memories as your other agents.

What Codex gets

Without a gateway, Codex connects to every MCP server on its own, loads each full tool list at connect and keeps its own logins.

With Runelay it connects to one endpoint, /v1/mcp. The gateway holds the credentials and exposes a small set of tools to search and call everything behind it. In our benchmark that was 1,045 context tokens at connect for 125 tools (Runelay 0.3.2, 14 Nov 2026, full numbers).

Set it up

  1. 1

    Run Runelay

    Use the desktop app, or install the server with Docker. Both serve the panel and the MCP endpoint on port 4312.

    $curl -fsSL runelay.com/install | sh
  2. 2

    Create a key

    In the panel, the agent setup guide creates a key that starts with rnl_. Each agent can have its own key, so you can revoke one without touching the others.

  3. 3

    Add it to ~/.codex/config.toml

    Replace the URL and the key with yours. With the desktop app the URL is http://127.0.0.1:4312/v1/mcp.

    [mcp_servers.runelay]
url = "https://runelay.example.com/v1/mcp"
http_headers = { Authorization = "Bearer rnl_..." }
  4. 4

    Or let the CLI do it

    runelay login saves a key for this computer and runelay connect registers Runelay in Claude Code, Codex, Cursor and Grok at once.

    $curl -fsSL runelay.com/cli | sh
    $runelay login && runelay connect
  5. 5

    Restart the agent

    Codex loads MCP servers when a session starts. Open a new session and the Runelay tools are there.

Bring what you already have

runelay migrate reads the MCP servers in your Codex config. On macOS it can read the OAuth tokens Codex keeps in the Keychain, so those accounts arrive connected.

runelay push sends ~/.codex/skills, ~/.codex/memories and ~/.codex/AGENTS.md. runelay pull writes the shared brief into AGENTS.md, only between the Runelay markers.

Once connected, in Codex

  • search_tools and call_tool reach every connected account, such as Linear, GitHub and Notion.
  • execute chains several calls in a sandboxed JavaScript runtime.
  • search_context, read_memory and write_memory share memory with your other agents.
  • read_skill serves the same skills to every agent.

Questions

Do my account tokens reach Codex?

No. Codex only holds the Runelay key. OAuth tokens and API keys stay on your server, encrypted with AES-256-GCM using your RUNELAY_SECRET.

Do I need Docker?

No. The desktop app for Mac, Windows and Linux runs the same server on your computer. Docker is for a server that stays on.

Can I keep the MCP servers I already configured?

Yes. Runelay is one more MCP server in the config. If you migrate them, running runelay migrate --replace removes the migrated ones and leaves only Runelay.

How do I use Linear in Codex?

Connect Linear once in the Runelay panel. Codex reaches it through the Runelay endpoint, with no Linear entry in config.toml.
