Hugging Face no Runelay, gateway MCP open source

Conecte o Hugging Face uma vez. Claude Code, Cursor, Codex e Grok usam essa mesma conexão, e a credencial não sai do seu servidor.

O que essa conexão faz

Modelos, datasets e Spaces. O Runelay se conecta ao servidor MCP remoto do Hugging Face em https://huggingface.co/mcp e coloca as tools dele atrás do seu endpoint.

Os agentes encontram as tools com search_tools e executam com call_tool, então a lista de tools do Hugging Face só entra no contexto quando é necessária.

  2. 2

    Pronto

    O Hugging Face não pede login. Todo agente com uma chave do Runelay pode usar a conexão.

Usar o Hugging Face nos agentes

Os agentes não precisam de uma entrada própria do Hugging Face. Aponte cada um para o Runelay e o Hugging Face aparece.

Perguntas

A credencial do Hugging Face chega ao agente?

O Hugging Face não usa credencial. Os agentes guardam só a chave do Runelay.

Preciso conectar o Hugging Face em cada agente?

Não. Você conecta uma vez no Runelay, e todo agente que aponta para o seu endpoint usa a mesma conexão.

Já tenho o Hugging Face configurado num agente. Dá para trazer?

Sim. O runelay migrate lê os servidores MCP que os agentes já têm. Se a CLI consegue ler o token, a conta chega conectada; senão, espera na fila de reconexão do painel.
