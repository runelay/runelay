Gmail no Runelay, gateway MCP open source

Mande e-mail pelos agentes com a permissão mais estreita que o Google oferece no Gmail. A conexão envia, e é só isso que ela faz.

Feito dentro do Runelay

O Runelay chama a Gmail API direto com o seu token do Google, sem servidor MCP de terceiros no meio. account_whoami mostra qual conta Google está conectada.

Tools

  • Enviar. send_email manda uma mensagem em texto pela conta conectada para um ou mais destinatários, com cópia opcional.
  • Sem leitura. O único escopo do Gmail pedido é gmail.send. O agente não lê, não busca e não apaga mensagens da sua caixa.

Peça assim

  • “Mande o resumo deste pull request para ana@example.com.”
  • “Envie as notas da reunião para as três pessoas do convite, comigo em cópia.”
  • “Escreva uma atualização curta para o meu gestor e envie.”

Como entra

  • OAuth do Google pelo broker do Runelay. Sem projeto próprio no Google Cloud; o Runelay renova o token.
  • Escopos: gmail.send, mais openid, userinfo.email e userinfo.profile.

O que essa conexão faz

Os agentes encontram essas tools com search_tools e executam com call_tool, então elas só entram no contexto quando a tarefa pede.

  3. 3

    Pronto

    O token fica criptografado no seu servidor e é renovado pelo Runelay. Todo agente com uma chave do Runelay pode usar a conexão.

Usar o Gmail nos agentes

Os agentes não precisam de uma entrada própria do Gmail. Aponte cada um para o Runelay e o Gmail aparece.

Perguntas

O agente lê a minha caixa de entrada?

Não. A conexão só pede gmail.send, que não lê, não busca e não apaga e-mail.

Ele manda HTML ou anexo?

Não. send_email manda texto puro com destinatário, cópia, assunto e corpo.

De qual endereço o e-mail sai?

Da conta Google que você conectou. account_whoami mostra qual é.
