GitHub no Runelay, gateway MCP open source

O servidor MCP oficial do GitHub, atrás do seu endpoint do Runelay. Faça login uma vez com OAuth e todo agente lê repositórios, trabalha em issues e cuida de pull requests com as suas permissões no GitHub.

O MCP do próprio GitHub, compartilhado por todos os agentes

O item do catálogo aponta para api.githubcopilot.com/mcp/, o servidor MCP remoto mantido pelo GitHub. O Runelay não embrulha nem reescreve as tools; ele guarda o token e repassa as chamadas.

O GitHub agrupa as tools em toolsets. O conjunto padrão documentado é context, repos, issues, pull requests e users, que cobre o trabalho do dia a dia abaixo.

O que o seu agente faz no GitHub

  • Repositórios e código. Lê arquivos com get_file_contents, busca com search_code e search_repositories, olha o histórico com list_commits e get_commit, e escreve com create_branch, create_or_update_file e push_files.
  • Issues. Encontra com list_issues e search_issues, lê uma com issue_read, abre ou edita com issue_write e cuida de sub-issues com sub_issue_write.
  • Pull requests. Lista, busca e lê pull requests, abre com create_pull_request, atualiza, deixa review com pull_request_review_write e faz merge com merge_pull_request.
  • Contexto. get_me diz em nome de quem o agente age, e search_users acha pessoas pelo nome.

Peça assim

  • “Resuma os pull requests abertos do meu repo e diga quais estão esperando por mim.”
  • “Ache onde o rate limiter está definido neste repositório e me explique.”
  • “Abra uma issue para o redirect de login quebrado com os passos que acabei de descrever.”

Como entra

  • OAuth pelo broker do Runelay. Você aprova um app OAuth do GitHub; não precisa registrar cliente próprio.
  • Escopos pedidos: repo e read:user. O agente alcança os repositórios que a sua conta do GitHub alcança, inclusive os privados.
  • Prefere token? Cole um token de acesso pessoal do GitHub no lugar, e as permissões dele viram o limite.

O que essa conexão faz

Repositórios, issues e pull requests. O Runelay se conecta ao servidor MCP remoto do GitHub em https://api.githubcopilot.com/mcp/ e coloca as tools dele atrás do seu endpoint.

Os agentes encontram as tools com search_tools e executam com call_tool, então a lista de tools do GitHub só entra no contexto quando é necessária.

Perguntas

O agente consegue fazer push ou merge de pull request?

Sim. Os toolsets padrão incluem push_files, create_or_update_file e merge_pull_request, então o agente escreve onde a sua conta escreve. Se for demais, conecte com um token fine-grained limitado aos repositórios e permissões que você escolher.

Ele vê os meus repositórios privados?

Com OAuth, sim: o escopo repo cobre os repositórios privados que a sua conta alcança. Um token fine-grained reduz isso aos repositórios que você marcar.

É o mesmo servidor que o Copilot usa?

É o servidor MCP remoto do GitHub em api.githubcopilot.com/mcp/, mantido pelo GitHub. O Runelay se conecta a ele a partir do seu servidor e guarda o token lá.
