O catálogo é um atalho, não um limite. O que você adicionar aparece para todos os agentes pelo mesmo endpoint.

Não está no catálogo? Adicione um conector personalizadoMCP remoto, comando local ou spec OpenAPI, com o seu próprio cliente OAuth se precisar.

Perguntas

Todas as integrações usam OAuth?

Não. A maioria usa OAuth, inclusive GitHub e Google, alguns pedem uma chave de API e alguns servidores públicos não pedem login. Cada item mostra qual é o caso.

Quem roda esses servidores MCP?

Cada item aponta para um servidor MCP remoto no domínio do próprio provedor. O Runelay se conecta a ele a partir do seu servidor e guarda a credencial.

Posso pedir uma integração nova?

Abra uma issue em github.com/Andsu-dev/runelay. Enquanto isso, qualquer URL de MCP remoto pode ser adicionada pelo painel.
