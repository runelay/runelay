Runelay não é Runlayer

O Runelay, gateway MCP open source, é um projeto gratuito que você mesmo hospeda. O Runlayer é outra empresa, com um produto enterprise. Os nomes diferem em uma letra, então os buscadores costumam trocar um pelo outro.

Você procura o Runelay se

  • Usa Claude Code, Codex, Cursor ou Grok e quer que eles dividam contas, skills e memórias.
  • Quer um app desktop ou um container no seu servidor.
  • Viu runelay migrate, runelay connect ou uma chave que começa com rnl_.

Você procura o Runlayer se

  • Está avaliando uma plataforma de governança de agentes para a empresa.
  • Precisa de políticas, aprovações e scanners de segurança geridos por um fornecedor.
  • Recebeu um link de runlayer.com ou docs.runlayer.com.

Sobre o nome

Runelay se escreve com “e” depois de “run”. O projeto e o site são runelay.com e github.com/Andsu-dev/runelay. Não tem relação com o Runlayer e não afirma nada sobre aquele produto além do que o próprio site dele diz.

Perguntas

O Runelay tem relação com o Runlayer?

Não. São projetos separados, de autores diferentes. O Runelay é um gateway MCP com licença MIT, feito por Anderson Medeiros.

Por que a busca mostra o Runlayer quando digito runelay?

Os nomes diferem em uma letra, então buscadores e assistentes corrigem um para o outro. Buscar “runelay MCP gateway” ou abrir runelay.com direto evita isso.

Onde baixo o Runelay?

Em runelay.com/download para Mac, Windows e Linux, ou com curl -fsSL runelay.com/install | sh num servidor com Docker.
