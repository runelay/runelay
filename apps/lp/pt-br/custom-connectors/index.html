Conecte qualquer servidor MCP ou API

O catálogo é um atalho, não um limite. Adicione um servidor MCP remoto, um comando local ou uma spec OpenAPI ao Runelay, gateway MCP open source, e todos os agentes recebem as tools pelo mesmo endpoint.

Três jeitos de conectar

O que você informaServe para
MCP remotoA URL do servidorServidores MCP públicos ou internos via HTTP
Comando localUm comando, argumentos e variáveis de ambienteServidores MCP que rodam como processo, como pacotes npx
OpenAPIUma spec em JSON ou YAMLA sua própria API REST, sem escrever servidor MCP. Cada operação vira uma tool.

Login sem complicação

  • Cole a URL de um MCP remoto e o Runelay detecta se ele pede OAuth, uma chave no header ou nada.
  • O OAuth roda quando você salva. Os tokens ficam criptografados e são renovados pelo Runelay.
  • Provedor sem registro automático de cliente, como o Google? Use o seu próprio cliente OAuth: cadastre PUBLIC_URL/v1/oauth/callback como URL de redirecionamento e cole o Client ID e o secret.
  • Headers, variáveis de ambiente e secrets ficam criptografados com AES-256-GCM. Os agentes nunca veem.

Um login, todos os agentes

O nome da conexão vira o prefixo das tools, então uma conexão chamada billing expõe tools como billing.list_invoices. Claude Code, Cursor, Codex e qualquer outro agente com uma chave do Runelay encontram as tools com search_tools e executam com call_tool.

Já está configurado num agente? runelay import transforma em conexões os servidores MCP das configurações dos agentes, ou cole o arquivo de configuração no painel.

  1. 1

  3. 3

    O Runelay conecta, faz login se precisar e lista as tools. A referência completa está na documentação de conectores personalizados.

Perguntas

O Runelay alcança um servidor na minha rede privada?

Sim, se você liberar. Requisições para endereços privados, de loopback e link-local são bloqueadas por padrão. Defina RUNELAY_ALLOW_PRIVATE_URLS=true no servidor do Runelay para alcançar servidores internos.

Dá para rodar um servidor MCP local com npx?

Sim. O app desktop roda comandos locais com as ferramentas instaladas no seu computador. Num servidor eles vêm desligados: defina RUNELAY_ENABLE_STDIO=true, e só um owner ou admin consegue criar. A imagem Docker não traz Node.

As minhas chaves de API chegam aos agentes?

Não. Headers, variáveis de ambiente e tokens OAuth ficam no seu servidor, criptografados com o seu RUNELAY_SECRET. Os agentes guardam só a chave do Runelay.
