runelayRecurso · Memória

Memória compartilhada

Notas que todo agente lê e escreve. O que um agente aprende, todos sabem.

Ligadas e versionadas

As notas se ligam com [[slug]], e toda mudança gera uma versão. Os agentes leem com read_memory e salvam fatos novos com write_memory.

Checagem de saúde

O painel aponta memórias que merecem revisão: notas sem mexer há 30 dias, links que não levam a lugar nenhum e notas que nada liga.

Fixadas vão para todo lugar

Memórias fixadas entram nas instruções de todo agente, e só o painel fixa, nunca um agente. O runelay pull escreve o resumo no CLAUDE.md e no AGENTS.md, só entre os marcadores dele.

$runelay pull

Perguntas

A memória volta para arquivos locais?

Não. O resumo pede aos agentes que salvem fatos novos com write_memory, então a memória volta para o runelay em vez de arquivos locais.

Dá para trazer as memórias que eu já tenho?

Sim. O runelay push importa memórias e instruções globais do Claude Code, Codex, Cursor, Grok, Gemini e OpenCode.
