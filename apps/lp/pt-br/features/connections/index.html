runelayRecurso · Conexões

Conecte uma vez, use em todo lugar

Adicione uma conta ou uma tool ao runelay uma vez. Todo agente que aponta para o seu endpoint vê as tools, e a credencial não sai do seu servidor.

Catálogo com OAuth em um clique

Cerca de 25 servidores MCP selecionados. Escolha um, faça login e as tools estão prontas. O nome da conexão vira o prefixo das tools, então linear expõe tools como linear.list_issues.

Traga qualquer servidor MCP ou API

O catálogo é um atalho, não um limite. Três tipos de conexão cobrem o resto:

  • MCP remoto. Uma URL e headers opcionais, guardados criptografados. Se o servidor pedir login, o OAuth abre em seguida.
  • Comando local. Um comando que sobe um servidor MCP na máquina do runelay. Desligado por padrão, precisa de RUNELAY_ENABLE_STDIO=true.
  • OpenAPI. Uma spec em JSON ou YAML. Cada operação vira uma tool.

Login vencido espera numa fila

Cada conexão mostra quantas tools tem e um status: OK, Erro, Pede login ou Não testada. Dá para testar, pausar ou remover. Depois do runelay migrate, a fila de reconexão passa por cada login pendente, uma aba por vez.

$runelay migrate

Perguntas

Os agentes veem as minhas credenciais?

Não. Tokens e headers são criptografados com AES-256-GCM usando o seu RUNELAY_SECRET, e requisições feitas com chave de API veem tudo como ••••••.

Dá para importar os servidores MCP que eu já tenho?

Sim. Cole ~/.claude.json, ~/.codex/config.toml, ~/.grok/config.toml ou ~/.cursor/mcp.json no painel, ou rode runelay import no seu computador.

O que acontece quando removo uma conexão?

O login dela é apagado e as tools somem de todos os agentes da organização.
