Conecte o Claude Code ao Runelay

O Runelay, gateway MCP open source, dá ao Claude Code um endpoint para todas as contas que você conectou. Adicione uma vez e o Claude Code enxerga as mesmas tools, skills e memórias dos seus outros agentes.

O que o Claude Code ganha

Sem um gateway, o Claude Code se conecta a cada servidor MCP por conta própria, carrega a lista inteira de tools de cada um e guarda os próprios logins.

Com o Runelay ele se conecta a um endpoint, /v1/mcp. O gateway guarda as credenciais e expõe poucas tools para buscar e chamar tudo que está atrás dele. No nosso benchmark foram 1.045 tokens de contexto na conexão para 125 tools (Runelay 0.3.2, 14 nov 2026, números completos).

Passo a passo

  1. 1

    Rode o Runelay

    Use o app desktop ou instale o servidor com Docker. Os dois servem o painel e o endpoint MCP na porta 4312.

    $curl -fsSL runelay.com/install | sh
  2. 2

    Crie uma chave

    No painel, o guia de configuração de agentes cria uma chave que começa com rnl_. Cada agente pode ter a própria chave, então dá para revogar uma sem mexer nas outras.

  3. 3

    Adicione ao Claude Code

    Troque a URL e a chave pelas suas. Com o app desktop a URL é http://127.0.0.1:4312/v1/mcp.

    claude mcp add --scope user --transport http runelay https://runelay.example.com/v1/mcp \
  --header "Authorization: Bearer rnl_..."
  4. 4

    Ou deixe a CLI fazer

    runelay login salva uma chave para este computador e runelay connect registra o Runelay no Claude Code, Codex, Cursor e Grok de uma vez.

    $curl -fsSL runelay.com/cli | sh
    $runelay login && runelay connect
  5. 5

    Reinicie o agente

    O Claude Code carrega os servidores MCP quando a sessão começa. Abra uma sessão nova e as tools do Runelay aparecem.

Traga o que você já tem

runelay migrate lê os servidores MCP, as memórias, as skills e as instruções globais que o Claude Code já tem. No macOS ele consegue ler os tokens OAuth que o Claude Code guarda no Keychain, então essas contas chegam conectadas.

runelay push envia ~/.claude/skills, as memórias dos projetos e o ~/.claude/CLAUDE.md. runelay pull escreve o resumo compartilhado no CLAUDE.md, só entre os marcadores do Runelay.

Depois de conectado, no Claude Code

  • search_tools e call_tool alcançam todas as contas conectadas, como Linear, GitHub e Notion.
  • execute encadeia várias chamadas num runtime JavaScript isolado.
  • search_context, read_memory e write_memory compartilham memória com os outros agentes.
  • read_skill entrega as mesmas skills para todos os agentes.

Perguntas

Os tokens das minhas contas chegam ao Claude Code?

Não. O Claude Code guarda só a chave do Runelay. Tokens OAuth e chaves de API ficam no seu servidor, criptografados com AES-256-GCM usando o seu RUNELAY_SECRET.

Preciso de Docker?

Não. O app desktop para Mac, Windows e Linux roda o mesmo servidor no seu computador. O Docker é para um servidor que fica sempre ligado.

Posso manter os servidores MCP que já configurei?

Sim. O Runelay é mais um servidor MCP na configuração. Se você migrar os outros, runelay migrate --replace remove os migrados e deixa só o Runelay.

Por que --scope user?

O escopo de usuário deixa o Runelay disponível em todos os projetos deste computador, e não só na pasta atual.
