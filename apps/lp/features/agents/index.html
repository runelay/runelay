runelayFeature · Agents

Works with every agent

Claude Code, Codex, Cursor, Antigravity, Grokbot or any MCP client talks to one endpoint, with its own key.

One endpoint for all of them

Every agent talks to PUBLIC_URL/v1/mcp with its own API key (rnl_…). Adding a new agent is one key and one line of config.

Guides: Claude Code · Codex · Cursor · Antigravity · Grokbot · Hermes Agent · OpenClaw · MausBot · OpenCode · OpenBot · Kimi Code · agentes.chat

One key per agent

Each key belongs to one organization and has its own rate limit. Revoke one without breaking the others. Every request made with a key is audited: tool calls with source, tool, result and duration.

Set up in one command

runelay migrate brings the MCP servers, memories, skills and instructions your agents already have. runelay connect registers runelay in Claude Code, Codex, Cursor and Grok.

$runelay migrate
$runelay connect

Questions

Which agents does it work with?

Any MCP client. runelay connect wires Claude Code, Codex, Cursor and Grok for you; the others take the endpoint and a key.

Do agents get my account credentials?

No. They only hold their runelay key. Account tokens stay encrypted on your server.
