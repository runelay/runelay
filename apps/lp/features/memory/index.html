runelayFeature · Memory

Shared memory

Notes every agent reads and writes. What one agent learns, all of them know.

Linked and versioned

Notes link to each other with [[slug]], and every change is versioned. Agents read with read_memory and save new facts with write_memory.

Health checks

The panel flags memories worth reviewing: notes untouched for 30 days, links that point nowhere and notes nothing links to.

Pinned memories go everywhere

Pinned memories go into every agent's instructions, and only the panel can pin, never an agent. runelay pull writes the brief into CLAUDE.md and AGENTS.md, only between its own markers.

$runelay pull

Questions

Does memory go back to local files?

No. The brief tells agents to save new facts with write_memory, so memory flows back to runelay instead of local files.

Can I bring the memories I already have?

Yes. runelay push imports memories and global instructions from Claude Code, Codex, Cursor, Grok, Gemini and OpenCode.
