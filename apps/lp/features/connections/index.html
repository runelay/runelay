runelayFeature · Connections

Connect once, use everywhere

Add an account or a tool to runelay one time. Every agent that points at your endpoint sees its tools, and the credential never leaves your server.

A catalog with one-click OAuth

About 25 curated MCP servers. Pick one, sign in, and its tools are ready. The connection's name becomes the tool prefix, so linear exposes tools like linear.list_issues.

Bring any MCP server or API

The catalog is a shortcut, not a limit. Three connection types cover the rest:

  • Remote MCP. A URL plus optional headers, stored encrypted. If the server asks for sign-in, OAuth opens next.
  • Local command. A command that starts an MCP server on the runelay machine. Off by default, it needs RUNELAY_ENABLE_STDIO=true.
  • OpenAPI. A spec in JSON or YAML. Each operation becomes a tool.

Expired logins wait in a queue

Each connection shows its tool count and a status: OK, Error, Needs sign-in or Not tested. You can test, pause or remove it. After runelay migrate, the reconnect queue walks you through every pending login one tab at a time.

$runelay migrate

Questions

Do agents ever see my credentials?

No. Tokens and headers are encrypted with AES-256-GCM using your RUNELAY_SECRET, and requests made with an API key see them as ••••••.

Can I import the MCP servers I already have?

Yes. Paste ~/.claude.json, ~/.codex/config.toml, ~/.grok/config.toml or ~/.cursor/mcp.json in the panel, or run runelay import on your computer.

What happens when I remove a connection?

Its sign-in is deleted and its tools disappear from every agent in the organization.
