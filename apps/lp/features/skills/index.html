runelayFeature · Skills

Skills that travel

Keep your SKILL.md folders in one place. Any agent finds them and reads them only when it needs them.

Served on demand

Agents read a skill with read_skill and its extra files with read_skill_file. search_context runs a full-text search across skills and memories, so a skill only enters the context when it matters.

On or off, per skill

Every skill has a switch in the panel. Turn one off and it drops out of agent search and the brief, without deleting the folder.

Lands in your local folders

runelay push imports skills from Claude Code, Codex, Cursor, Grok, Gemini and OpenCode. runelay pull writes enabled skills you do not have locally to ~/.claude/skills/<slug>/ with a .runelay marker. A folder without the marker is yours and is never overwritten.

$runelay sync

Questions

Will runelay pull overwrite my own skills?

No. It only updates folders that carry the .runelay marker. A folder without it is yours.

Which folders does runelay push read?

~/.claude/skills, ~/.agents/skills, ~/.codex/skills, ~/.cursor/skills, ~/.grok/skills, ~/.gemini/skills and ~/.config/opencode/skills. Duplicates are merged.
